# Karakayaacademy Site

Next.js foundation for the boxing + functional training academy.

## Run locally

From this folder:

```bash
npm run dev
```

Then open:

`http://localhost:3000`

## Current capabilities

- Premium landing page with real local photography
- Inquiry form API route
- Class booking request API route
- Package checkout wiring for Stripe
- Supabase-ready database schema and environment template

## Recommended stack

- Frontend and hosting: Next.js + Vercel
- Database and auth: Supabase
- Payments and subscriptions: Stripe
- Domain: move DNS from GoDaddy to Vercel when ready

## Priority order

1. Inquiry capture
2. Intro and class booking
3. Simple package checkout
4. Member login and history
